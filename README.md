# Pholia (フォリア)

思い出が葉になり、絆が木になる。育てて楽しむ森のアルバム

![Pholia](img/Pholia.jpg)

## 概要

大切な人との思い出を撮りっぱなしにせず、一緒に思い出を育てる新しい写真共有アプリ
写真を葉っぱとして追加すると、関係性ごとに作った木が成長していく森育成アルバムです
思い出を振り返るきっかけをつくり、また会いたい”が生まれる関係づくりをサポートします
